# K-RÉENA — sitio oficial

Sitio estático minimalista para K-RÉENA.

## Incluye
- Hero full-screen con el video de YouTube `02yVcc5XkD8`.
- Autoplay, mute inicial y control de sonido.
- Navegación por anclas.
- Música y plataformas.
- Videos.
- Biografía.
- Redes sociales y contacto.
- Diseño responsive para móvil y desktop.
- Sin framework ni dependencias de JavaScript.

## Publicación
Puede subirse directamente a GitHub Pages, Netlify, Vercel o un servidor web tradicional.

## Assets
El hero utiliza el video proporcionado y su thumbnail de YouTube. La sección editorial de artista está preparada para incorporar la fotografía/logotipo original de K-RÉENA cuando se disponga del archivo original con autorización de uso.
